# Creator-Team3
# CreatorIQ – Creator Analytics & Content Performance Dashboard

## Project Overview

CreatorIQ is a creator analytics and content performance dashboard designed to help content creators monitor social media performance, audience engagement, content growth, and monetization insights through a centralized platform.

The project is developed as a team project, with different members contributing to different modules and milestones.


# Technology Stack

### Frontend

* React.js
* JavaScript
* Tailwind CSS
* Chart.js / Recharts
* Axios

### Backend

* Python
* FastAPI
* SQLAlchemy
* Pydantic

### Database

* PostgreSQL

### APIs

* YouTube Data API
* Instagram Graph API
* LinkedIn API
* Other platform APIs as required

### Development Tools

* VS Code
* Git & GitHub
* FastAPI Swagger UI

# Conclusion

CreatorIQ was developed incrementally through four milestones. Each milestone introduced a specific set of functionalities, starting with project initialization and core system setup, followed by analytics and social media integration, revenue and reporting features, and finally testing, deployment, and documentation.

The milestone-based development approach provides a clear record of the team's progress and makes it possible to track the implementation of individual features throughout the project.
